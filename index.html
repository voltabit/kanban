    Manage statuses

    Each status becomes a board column. Mark a status as “Completed” so its tasks are not flagged as overdue. Deleting a status moves its tasks to the first status.

    Import tasks

    Projects in the file

    Update overwrites your copy of each checked project that is already here with the one in the file, and adds the others. Changes made in your copy since are lost, so agree on them first.

    Add selected keeps your projects and adds the checked ones as new projects; a name that is already used gets a number. Replace all removes your current projects and keeps only the checked ones. You can undo any of these right after.

    Board background

    A file name is looked up next to index.html. A web image's host can see your IP address when the image loads.

    New project

    Your current project also stays saved in this browser. Open it again from Projects.

    Manage projects

    Rename projects or delete them with all their tasks. Changes apply when you save, and you can undo right after.

    Manage workers

    Workers are shared by all projects and listed in the “Assigned to” field. Renaming a worker updates their tasks in every project. Removing a worker keeps the name on existing tasks.
